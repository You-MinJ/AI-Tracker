# 다음 채팅 인계

아래 문구를 새 Codex 채팅에서 사용한다.

> AI-Tracker 저장소의 AGENTS.md, README.md, docs/CURRENT.md, docs/DECISIONS.md를 먼저 읽고 현재 Git 변경과 실행환경을 확인해 줘. 목표는 AI 산출물 품질 향상이며, docs/PLAN.md와 docs/wireframes.html은 아직 검토안이야. 내가 선택한 기능과 완료조건을 확정한 뒤 그 범위만 개발해 줘. 진행 중 대화 미표시와 최신 턴 중심으로 누적 추적이 부족한 문제를 해결됐다고 가정하지 마. 실행·수집·품질 상태를 구분하고, 실제 대화/ID/경로/비밀은 공개하지 마. Stop 재시험·원격접속·승인 실행은 보류야. 우선 기획과 화면의 검토할 결정사항을 짧게 정리해 줘.
