이 정보가 필요한 이유

검토할 결과를 실행량 대신 산출물과 미해결 조건으로 골라, 사람이 먼저 읽을 대상을 정합니다.

필요한 데이터

업무·선택 턴의 산출물, 완료조건, 검증 근거와 사람 검토 상태. 실행·수집·품질은 독립 정보입니다.

완료 기준

홈에서 산출물 본문, 진행 사례, 질문 문장의 출처에 접근하고, 종료 기록이 품질 통과로 표시되지 않아야 합니다.
