어떤 Sub-agent가 무엇을 맡았나요?

이 페이지에서 무엇을 판단하나
내가 정의한 역할뿐 아니라 관측된 모든 일반 하위 실행의 지시·결과·검증 범위를 확인합니다.

역할 이름으로 표시 범위를 제한하지 않습니다. 모두 완전 합성 예시입니다. explorer·worker·사용자 정의·역할 미제공 실행을 함께 보여줍니다. 역할 이름만으로 기본 제공 여부나 만든 사람을 판단하지 않습니다.

이 페이지의 핵심

  • 역할 종류보다 실제로 맡긴 업무를 먼저 읽기
  • 공개 결과가 부모 결과에 어떻게 쓰였는지 검토
  • 토큰·시간은 공식 제공 범위 안에서 상세 확인
  • 결과가 있다는 이유로 품질 통과 처리하지 않기

사용량을 확인하려면

실제 앱의 실행 상세에서 지시·도구·최종 결과·실패·검증 명령을 확인합니다. 공식 토큰이 미제공이면 미제공으로 표시하며 부모·자식 토큰을 추정 합산하지 않습니다.

일반 실행과 Hooks 시험

일반 Sub-agent 화면은 특정 역할명을 제한하지 않습니다. 기존 Hooks는 별도 승인된 두 역할의 제한 실험입니다. 이 시안에서 수집 범위를 확대하거나 시험을 재실행하지 않습니다.

목적

내가 만든 역할 외의 하위 실행도 어떤 일을 맡고 어떤 결과를 냈는지 검토합니다.

필요한 데이터

공식 출처·부모 관계·실행 역할·같은 턴 지시와 결과·모델·검증·사용량. 없는 역할명과 사용량은 추정하지 않습니다.

완료 기준

특정 역할명 제한 없이 일반 하위 실행을 보여주고, 역할 미제공·부분 관측을 보존하며 내부 안전·시스템 실행을 제외합니다.
