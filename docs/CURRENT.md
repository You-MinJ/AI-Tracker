# 현재 상태

이 문서는 공개 코드 기준을 설명한다. 로컬 개인 서버의 동작·데이터를 원격으로 보증하지 않는다.

## 확인된 구현

- React/Vite/TypeScript 화면 + Node 읽기 서버. localhost 고정, GET/Host/Origin 검사.
- 결과 검토함과 보조 업무 목록, 프로젝트/검색 필터. 최신 턴 요약을 중심으로 표시.
- 상세의 같은 턴 지시·공개 도구·최종 응답·검증 명령, 40항목 페이지 추가.
- 턴 목록 8개씩 조회, 선택·이전 턴 추가 읽기. 늦은 A 응답으로 선택 B가 덮이지 않도록 세대/요청 순서 검사.
- 실제 API 필드가 있을 때만 시간/모델/토큰/관계 표시. 반복 호출과 실패 근거를 구분. 내부 실행 필터와 비밀 마스킹.
- 제한 Hooks 수집기와 시험 화면. 네 종류 allowlist, 마커 등록 세션, 두 시험 역할 matcher, 로컬 14일 정책. 공개본은 활성 설정과 이벤트를 포함하지 않음.

## 해결되지 않은 사용자 문제보고

| 사용자 경험 | 코드에서 확인한 사실 | 판정 |
|---|---|---|
| 진행 중인 대화가 안 보임 | 별도 App Server의 저장 DB 읽기. 전체 앱/클라우드 런타임 구독은 없음 | 미해결. 현재 공급 범위와 실시간 노출 가능성 확인 필요 |
| 최신 대화만 보여 누적 추적이 부족 | 홈은 최신 턴 요약. 상세에 과거 턴 선택/페이지 API는 있음 | 전체 이력 UX·누적 근거 모델은 미구현. 과거턴 API 존재로 해결 처리 금지 |
| 역할별 품질·위임 가치 판단이 필요 | 관계가 있는 실행 사례와 호출 근거만 제공 | 품질 기준/사용자 평가/산출물 채택/재작업 연계는 기획 단계 |

## 수집 범위·누락

App Server: thread/list(useStateDbOnly:true) 비보관 최대1000개, 메타데이터 최대100개/5분 캐시, 최근24개 턴 요약/60초 캐시. 목록15초 폴링, 상세는 사용자 요청 시 읽는다. 큰 이력의 누락/페이지 여부를 보존해야 한다. 등록 프로젝트 전체나 GPT의 모든 작업 수집을 의미하지 않는다.

상세는 thread/turn/items 지원 읽기 경로만 쓴다. threadUsage=null을 관측한 경우 토큰 미제공이다. 부모·자식/턴 사용량 범위 추정과 비용 환산을 하지 않는다. 공식 pending 승인 목록은 미연결이다.

제한 Hooks 실험에서는 사용자 요청과 두 역할의 시작/종료·공개 결과를 확인했지만 부모 Stop 누락이 남았다. 추가 시험·원인 확정·설정 변경은 보류다. 실제 식별자/원문/화면 증거는 공개하지 않는다. 시험 역할 활동을 일반 업무 성과와 합치지 않는다.

## 공개 기준 검증

공개 복사본에서 공식 npm HTTPS 등록소와 잠금 파일 integrity를 확인한 뒤 승인된 npm ci를 수행했다. 잠금 파일은 바뀌지 않았으며 22개 합성 단위·회귀 테스트, TypeScript 검사, Vite production 빌드가 모두 통과했다. 이전 복사 의존성의 플랫폼 불일치는 재설치 후 해소됐다. 기존 앱·실제 기록·파일 권한은 변경하지 않았다. 개인 데이터 없는 36개 공개 파일을 대상으로 staged 전체 내용과 비밀/식별 패턴을 검토했다. 자동 검사로 완전한 안전을 보증하지 않는다.

테스트 범위: 턴 경계, 내부 실행 제외, 비밀 마스킹, 질문 후보, 반복/검증 명령 근거, 선택 변경 지연 응답, Hooks allowlist/보관정책. 검증은 이 공개 코드 기준이며 실제 연결 재검증/전체 이력 기능 완료를 뜻하지 않는다. 과거 로컬 실제 업무 연결 확인은 새 설치에서의 연결 성공을 대신하지 않는다.

4. 역할 비교는 연결 증거·통제조건·표본이 확보된 후 검토.
